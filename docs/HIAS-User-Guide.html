1. What HIAS does

HIAS assigns invigilators (staff) to examination halls for every exam session, and rotates those assignments fairly. It remembers who has already been in which hall, so nobody is sent to the same hall again until they have had a turn in every other hall of the rotation.

  • Fully offline. HIAS needs no internet connection and no server. Everything is stored on the computer it is installed on.
  • No login. The app opens straight to the dashboard. Keep it on a computer that only authorised people use.
  • Automatic rule checks. Before an allocation is confirmed, HIAS checks that no hall or person is double-booked, nobody repeats a hall too early, and inactive staff or halls are not used.

2. Installing HIAS

  1. Copy Hall Invigilator Allocation System Setup 1.0.0.exe to the computer and double-click it.
  2. If Windows shows "Windows protected your PC", click More info and then Run anyway. This appears because the installer is not code-signed; it is safe.
  3. Choose the installation folder (the default is fine) and click Install.
  4. Open HIAS from the HIAS shortcut on the desktop or from the Start menu.
Where is my data? All data is kept in one file on this computer: %APPDATA%\eias\eias.db. Updating or reinstalling HIAS keeps this file. Uninstalling the app does not delete it either. See section 9 for backups.

4. First-time setup

Do these steps once, in this order. You can come back and change anything later.

4.1 College profile and session timings

Open Settings → College Profile. The College Full Name is printed at the top of every PDF; the Short Name appears under the HIAS logo in the sidebar. Click Save.

Under Settings → Session Timings, set the usual reporting, start and end times for the Forenoon (FN) and Afternoon (AN) sessions. New batches start with these times; you can still change them per session.

4.2 Departments

Open Departments and add each department with a short Code (for example CSE) and a full Name. Reports use the short code.

4.3 Halls

Open Halls → Add Hall. Only the Hall Code (for example H101) is required; if you leave Hall Name empty, the code is used as the name. Capacity and Block are optional. Untick Active for a hall that is temporarily unavailable; inactive halls are never allocated.

4.4 Staff (invigilators)

Add staff one at a time with Add Staff, or many at once with Import Excel. The file HIAS-Staff-Import-Template.xlsx, supplied with HIAS, has the right headings ready. For an import, the first row of the sheet must contain these column headings:

ColumnRequired?Notes
Staff IDYesMust be unique. Rows whose Staff ID already exists are skipped.
NameYesFull name of the staff member.
DepartmentYesThe department's code or full name; it must already exist in Departments.
Designation, EmailNoOptional details.

After the import, HIAS shows how many staff were added and lists each skipped row with the reason (for example "Row 5: Department CIVIL does not match any existing department"), so you can correct the sheet and import it again.

Deactivate or delete? The bin icon first deactivates a staff member: they stay in past records but are no longer allocated. An inactive staff member with no allocation history can then be deleted permanently; HIAS asks you to type DELETE to confirm.

5. Creating an allocation batch

A batch is one examination series, such as an end-semester or internal assessment exam. Open Allocation Batches → New Allocation Batch. The wizard has three steps:

  1. Batch details. Enter the batch name, the academic year (for example 2026-27) and the number of exam days.
  2. Pick the dates on the calendar. Sundays and public holidays are highlighted so you do not pick them by mistake.
  3. Sessions and timings. For each date, choose Forenoon (FN), Afternoon (AN) or both. Timings come from Settings; expand a date to change its times.

To delete a whole batch, click its bin icon and type DELETE. This removes all its sessions, allocations and rotation records and cannot be undone.

6. Allocating invigilators to a session

Open a batch to reach its Allocation Workspace. Each session appears as a tab (for example 02 Nov 2026 FN).

  1. Select a session tab and click Select Staff & Generate.
  2. Tick the staff who are on duty and the halls in use for this session. The number of staff must equal the number of halls; HIAS tells you if they differ.
  3. Click Generate Allocation. HIAS assigns each person the next hall in their rotation.
  4. Review the list. To change one assignment, click the pencil on that row, choose a hall and, if you like, note the reason. HIAS only offers halls that keep the rules satisfied. Regenerate starts the session over.
  5. Click Confirm Allocation. HIAS runs all rule checks; if something is wrong it explains what, and nothing is saved until it is fixed.
  6. Click Export PDF to save the printable allocation sheet for this session.
Why confirming matters. The rotation only moves forward when a session is confirmed. Always confirm sessions in date order, so each session continues the rotation from the one before it.

The rules HIAS checks

RuleMeaning
R1A staff member does not return to a hall until they have been through the other halls in the rotation.
R2A hall gets only one invigilator per session.
R3A staff member is in only one hall per session.
R4Sessions are confirmed in rotation order.
R5 / R6Inactive staff and inactive halls are never used.
R7The number of staff equals the number of halls.

8. Allocation history

Allocation History lets you look up any past confirmed allocation. Filter by batch, session, staff member or hall and click Search Records. This is the quickest way to answer "Where was this person on that day?".

9. Backup and restore

HIAS keeps its data only on this computer. If the computer fails and there is no backup, the data cannot be recovered. Take a backup after every allocation batch and keep it on a pen drive or another computer.

To take a backup

  1. Open Settings → Backup & Restore and click Backup Database.
  2. Choose where to save the file (for example a pen drive). The file is named hias-backup.db by default; adding the date to the name helps.

To restore a backup

  1. Open Settings → Backup & Restore and click Restore Database.
  2. Choose the backup file and confirm. HIAS first saves a safety copy of the current data (eias.db.bak in the data folder), then replaces it.
  3. HIAS restarts by itself a moment later and opens with the restored data.

The same steps move HIAS to a new computer: back up on the old computer, install HIAS on the new one, and restore.

10. Restarting the rotation

Settings → Restart Rotation clears the whole rotation history, so every staff member starts again from the first hall. Use it only at a genuine new start, such as the beginning of an academic year. You must type RESTART to confirm. Past allocations and reports are not deleted; only the rotation memory is cleared.

11. Troubleshooting and FAQ

ProblemWhat to do
"Staff count must equal hall count"Select the same number of staff and halls for the session.
A staff member or hall is missing from the selection listCheck it is marked Active in Staff or Halls.
Confirm is refused with a rule message (R1–R7)Read the message; it names the person or hall. Edit that row, or regenerate, then confirm again.
Windows says "Windows protected your PC" when installingClick More info → Run anyway. The installer is not code-signed.
The app shows an error box at start-upNote the message, then restore the latest backup (section 9). The message is shown because a silent failure would give no clue.
Can two computers share the same data?No. Each installation has its own data. Use one computer for allocation, and move data with backup and restore if needed.
Does HIAS need the internet?No. It works completely offline.
